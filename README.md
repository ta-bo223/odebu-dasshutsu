# おデブ脱出大作戦 — iPhone対応版 v1.5

無料の個人・友人向け食事・運動記録アプリ。料理名候補の端末内AI（試験版）・写真保存・食事と運動の記録。広告・有料API・サーバー解析なし。
HTML / JavaScript / アイコン / Service Workerだけで動きます。

## 公開するファイル
このフォルダ内のファイルだけを新しい公開リポジトリへ配置してください。
GitHub Pagesの公開元をmainブランチのルートに設定します。
既存の下僕プロジェクト、個人データ、バックアップ、認証情報は絶対に含めません。
公開前に、所有者からアプリ本体とコードの一般公開について承認を得てください。
カスタムドメインや有料プランは不要です。GitHub Free / 公開リポジトリでのPages利用を想定しています。

## iPhone
公開URLをSafariで開く → 設定の「オフライン準備完了」を確認 → 共有 → ホーム画面に追加。
初回とアプリ更新には通信が必要です。Safariとホーム画面版でデータ領域が異なる場合はバックアップを移してください。
記録は同じ端末の同じサイトの保存領域に置かれます。端末消去・サイトデータ消去に備えてバックアップしてください。

## 更新
同じ公開URLで更新してください。記録キーkarada-note-v1は維持しています。
新しいService Workerは、古い画面を閉じて開き直した後に有効になります。
コード公開時に食事・体重などの実データは含まれません。
食事記録を外部送信する処理はありませんが、ホスティング事業者には通常のアクセス情報が届きます。

## v1.5 料理候補AI（試験版）
写真を添付後、解析ボタンを押すと料理名候補を表示。料理名を選んでも自動保存せず、量・カロリーは利用者が確認・入力します。写真から量やカロリーを算出する機能はありません。
初回はモデル約93MBと実行部品をHugging Face/jsDelivrから取得します。写真はWorker内で解析し、外部解析APIへ送信しません。ダウンロード先には通常のアクセス情報が届きます。通信料金は各自の通信契約に従います。
101種類からの分類なので、対象外の料理や非食品でも誤った候補になることがあります。スコアは正解確率ではありません。0.3未満は候補を出さない設計です。食品サンプル1枚の分類動作と非食品アイコンの低スコアをChromeで確認。精度保証やiPhone実機の性能検証ではありません。
週1〜7回の運動日を選択。筋トレは最大週3回、追加日は歩行。
